# لولووو وورد – خدي راحة + تنزيل PDF مباشر

الملفات المطلوب رفعها إلى جذر مستودع `lolooo-word` على GitHub:
- `index.html`
- `style.css`
- `script.js`
- `config.js`
- مجلد `assets` بما فيه `logo.png`

## التعديلات
- إزالة زر تنزيل HTML (مع بقاء استيراد ملفات TXT / HTML).
- إضافة قسم «خدي راحة»: حركات بسيطة للرقبة والظهر والعين، ونصائح مذاكرة، ونكتة يولدها Nour Ai باستخدام Worker الموجود.
- تنزيل PDF مباشرة من زر «حفظ PDF» دون استدعاء `window.print()`؛ باستخدام html2pdf.js. تتطلب المكتبة اتصالًا بالإنترنت لأنها تُحمّل من cdnjs.
- إبقاء إعداد Gemini الحالي دون تضمين مفتاح سري.

## تنبيهات
- في بعض الهواتف يتدخل نظام المتصفح باختيار مجلد التنزيل أو عرض قائمة المشاركة، حتى لو لم تظهر نافذة الطباعة.
- PDF ينتج من صورة تخطيط الصفحة؛ نصوصه قد لا تكون قابلة للبحث أو التحديد بالكامل. الخطوط والنصوص العربية تحتاج اختبارًا على الهاتف والمتصفح المستخدم.
- البيانات القديمة المخزنة في localStorage على github.io لا تنتقل تلقائيًا إلى loloword.online، لأن لكل نطاق مساحة تخزين منفصلة.
- لا تحذف التخزين أو ملفات المستندات القديمة قبل الاحتفاظ بنسخة من المستندات المهمة.
