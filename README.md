# لولووو وورد — التحديث المتقدم

## الجديد
- 💬 محادثة متعددة الرسائل مع Nour Ai باستخدام نفس Cloudflare Worker (سياق الجلسة، غير محفوظ).
- 💾 الحفظ التلقائي المحلي كما كان، مع تصدير واستيراد نسخة احتياطية JSON لكل ملف شخصي.
- 🎙️ كتابة بالصوت عبر SpeechRecognition عند دعم المتصفح والسماح بالميكروفون.
- 📝 اختبارات اختيار من متعدد من نص المستند، والتصحيح فور اختيار الإجابة.
- 📄 استيراد DOCX وPDF النصّي إضافةً إلى TXT وHTML. ملفات DOC القديمة وPDF المصوَّر غير مدعومة.
- ☁️ تسجيل الدخول ورفع/استرجاع نسخة سحابية اختياريًا عبر Supabase بعد الإعداد المذكور في CLOUD_SETUP.md. **ليست مزامنة فورية/تلقائية.**
- 📚 تنسيق مراجع مبسط من بيانات المصدر التي تدخلها المستخدمة، لا إنشاء مصادر وهمية أو تحقق تلقائي منها.
- الحفاظ على اللوجو ومساحة التحرير و«خدي راحة» وNour Ai وتصدير PDF.

## النشر
1. **قبل الرفع:** حمّل نسخة احتياطية JSON من مستندات كل ملف شخصي، واحفظ نسخة من مشروع GitHub الحالي إذا كنت تريد الرجوع للإصدار السابق.
2. ارفع `index.html`, `style.css`, `script.js`, `advanced.js`, `config.js`, ومجلد `assets` إلى **جذر مستودع GitHub Pages**. يمكنك إضافة هذا الملف و`CLOUD_SETUP.md` و`supabase.sql` للتوثيق.
3. افحص الموقع على `https://www.loloword.online/` مع تحديث الصفحة (`Ctrl+F5`).
4. تحتاج مزايا الاستيراد إلى اتصال الإنترنت لتحميل المكتبات الخارجية. وقد لا تتطابق التنسيقات 100%.
5. تأكد أن Cloudflare Worker يسمح لـ `https://www.loloword.online` وللنطاق المستخدم فعلًا، وأنه يرجع حقل `text`.
6. لتفعيل الحسابات والحفظ السحابي افتح `CLOUD_SETUP.md`، ولا تضع مفاتيح Gemini أو Supabase السرية في كود المتصفح.

## حدود مهمة
- كلمات المرور المكتوبة في نافذة الملف الشخصي الأصلية ليست مصادقة آمنة؛ استخدم تسجيل الدخول السحابي الحقيقي لحماية بيانات السحابة.
- التخزين المحلي مرتبط بالمتصفح والدومين؛ الانتقال من github.io إلى loloword.online لا ينقل التخزين القديم تلقائيًا.
- أزرار السحابة لا تعمل قبل ربط مشروع Supabase.
- الاستيراد من PDF يستخرج النص القابل للتحديد ولا يضمن إعادة تخطيط الصفحات.
- نتائج Gemini قد تحتاج مراجعة، خصوصًا الأسئلة والمراجع.
