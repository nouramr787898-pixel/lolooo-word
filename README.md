# لولووو وورد — Nour Ai (تصميم جديد)

## النشر على GitHub Pages
ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع: index.html و style.css و script.js و config.js ومجلد assets.
في Settings → Pages اختر main / (root). ثم حدّث الصفحة باستخدام Ctrl+F5.

## المميزات
واجهة عربية بأيقونات SVG محلية، محرر مستندات وتصدير PDF، ملف مستخدم لكل من أسماء وحماتي وجودي وحبيبة، ترحيبات متحركة وكلمة مرور واجهة لأسماء (`na`).

**تنبيه خصوصية:** كلمة المرور `na` فحص داخل المتصفح فقط، وليست حماية أمنية حقيقية؛ يمكن مشاهدة الكود، والملفات تحفظ في localStorage على الجهاز ولا تتزامن بين الأجهزة. للاستخدام الحقيقي مع حسابات خاصة يلزم تسجيل دخول وقاعدة بيانات وخادم.

قسم Nour Ai هو اسم واجهة المساعد؛ تشغيل الذكاء الاصطناعي يتطلب إعداد خدمة Cloudflare Worker ومفتاح Gemini API بشكل سري كما في ملفات cloudflare-worker و config.js. لم تتم تهيئة الربط تلقائيًا.
