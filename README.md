# لولووو وورد — نسخة أبسط بدون سحابة

هذه النسخة أزالت قسم «حسابي والمزامنة» وكل أكواد Supabase من الواجهة، مع تحسين التنسيق والتجاوب على الكمبيوتر والموبايل.

## ما زال يعمل
- المحرر والمستندات المحفوظة تلقائيًا داخل المتصفح (LocalStorage).
- نسخ احتياطية يدوية بصيغة JSON واسترجاع المستندات دون حذف الموجودة.
- Nour Ai عبر Cloudflare Worker الحالي (لا تضع أي مفتاح Gemini في هذا المشروع).
- محادثة Nour Ai، اختبارات، مساعد مراجع، إملاء صوتي في المتصفحات المتوافقة.
- استيراد DOCX وPDF النصي وTXT وHTML، وتنزيل PDF باستخدام مكتبة html2pdf.
- شعار الموقع والأقسام والتعريفات الحالية.

## النشر
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages. احتفظ بنسخة احتياطية من الملفات القديمة أولًا. لا تحتاج Supabase أو أي كلمة مرور.

## مهم
المستندات تبقى في الجهاز والمتصفح الحالي فقط. حذف بيانات الموقع أو تبديل الجهاز قد يفقدها، لذا استخدم تصدير نسخة احتياطية بانتظام. لم يتم حذف أي مستندات محفوظة في المتصفح عبر هذا التحديث.
