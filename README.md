# لولو وورد

موقع مجاني لمحرر مستندات عربي/إنجليزي يعمل على GitHub Pages.

## رفع الموقع إلى GitHub Pages
1. افتح مستودع GitHub عام (Public).
2. ارفع `index.html` و `style.css` و `script.js` ومجلد `assets` (وبداخله `logo.png`) إلى جذر المستودع.
3. من Settings > Pages، اختر Deploy from a branch ثم main و /(root).
4. افتح رابط الموقع بعد اكتمال النشر.

## الاستخدام
- احفظ مستنداتك من زر «حفظ المستند». التخزين محلي على متصفحك فقط.
- احفظ نسخة HTML احتياطية من زر «تنزيل HTML».
- صدّر PDF من زر «حفظ PDF» ثم اختر «Save as PDF» في نافذة الطباعة.
- مساعد الكتابة يقدم **قوالب محلية جاهزة**، وليس نموذج ذكاء اصطناعي متصل بالإنترنت.

## ملاحظات
- تنظيف بيانات المتصفح قد يمحو المستندات، ولذلك احتفظ بنسخ HTML احتياطية.
- إدراج صور كبيرة قد يستهلك مساحة التخزين المحلية.
- الذكاء الاصطناعي الحقيقي يتطلب خادمًا خلفيًا ومفتاح API محفوظًا بشكل آمن، ولا ينبغي نشره في JavaScript الخاص بالموقع.
