# لولووو وورد — إصلاح الترحيب و Nour Ai

## سبب مشكلة النسخة السابقة
كان ملف `script.js` يُستدعى في صفحة HTML قبل إنشاء نافذتي الترحيب وكلمة المرور، مما يوقف JavaScript عند محاولة ربط عناصر لم يتم تحميلها بعد.

## كيفية التحديث على GitHub
1. فك الضغط.
2. ارفع `index.html` و`style.css` و`script.js` و`config.js` ومجلد `assets` إلى **جذر المستودع** (وليس داخل مجلد إضافي).
3. وافق على استبدال الملفات القديمة.
4. انتظر نجاح GitHub Pages ثم اضغط Ctrl+F5.
5. اضغط على «أسماء»، أدخل `na`، ثم شاهد الاحتفال، أو جرّب بقية الأسماء.

لا تحذف بيانات الموقع من المتصفح لأن المستندات محفوظة في localStorage. كلمة المرور `na` تجريبية في واجهة المتصفح، وليست تأمينًا حقيقيًا للمستندات.
ربط Nour Ai مع Gemini API ما زال يتطلب إعداد Cloudflare Worker ومفتاح API سري.
